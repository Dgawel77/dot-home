# Dot Home

A black-and-white, dot-drawn home screen for a Galaxy Z Fold6: a tilt-steered space-shooter live wallpaper,
dot-matrix widgets, a dot radar, and a glyph icon pack, all on top of Samsung's own home screen.

- Design: `~/Documents/programs/docs/superpowers/specs/2026-11-15-fold6-home-screen-design.md`
- Phase 1 plan: `~/Documents/programs/docs/superpowers/plans/2026-11-15-fold6-dot-home-phase1.md`
- Builds and tests run on the NAS: `tools/nas ./test.sh`, `tools/nas ./build.sh`.
